# 1. requirement.txt

우선 본인의 가상환경을 실행합니다.

```bash
(예시)
source ~/work/env/bin/activate
```

아래 코드를 실행하여 requirements.txt에 첨부된 pip list를 다운받습니다.

```bash
pip install -r requirements.txt
```

# 2. Inference.py

Inference.py는 scissors(가위), rock(바위), paper(보)를 잘 인식하는지 확인할 수 있는 코드입니다.

아래 코드를 실행하여 Inference.py를 실행합니다.

```bash
python Inference.py
```


# 3. Inference_rev.py

Inference_rev.py는 가위바위보 게임을 할 수 있는 코드입니다.

아래 코드를 실행하여 Inference_rev.py를 실행합니다.
```bash
python Inference_rev.py
```
